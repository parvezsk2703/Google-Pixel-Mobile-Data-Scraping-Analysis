# Google Pixel Mobile Data Analysis

## Project Overview
This project collects and analyzes Google Pixel smartphone data from Flipkart using Python web scraping techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- BeautifulSoup
- Requests
- Matplotlib
- Seaborn

## Features
- Web scraping of Google Pixel smartphone data
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Dataset generation for further analytics

## Dataset Attributes
- Brand
- Model
- Price
- Rating
- RAM
- Storage
- Display Size
- Display Type
- Back Camera
- Front Camera
- Processor
- Warranty

## Key Insights
- Price distribution across Pixel models
- Relationship between storage and pricing
- Rating comparison among models
- Hardware specification analysis
